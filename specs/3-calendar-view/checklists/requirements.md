## 機能要件

### カレンダー表示

- [ ] 現在日が含まれる月を初期表示
- [ ] 日曜日〜土曜日の週単位でグリッド表示
- [ ] 月の最初の週は前月の日付で埋められている（グレーアウト）
- [ ] 月の最後の週は次月の日付で埋められている（グレーアウト）
- [ ] 現在日が視覚的に強調表示される（背景色・枠線）
- [ ] 曜日ヘッダー（日月火水木金土）が表示される
- [ ] 年月が明確に表示される（例: 2025年11月）

### トレーニング記録マーク

- [ ] 記録がある日付に⭐マークが表示される
- [ ] 記録が複数ある日も⭐は1つのみ表示
- [ ] ⭐マークがクリック可能であることが分かる（カーソル変更）
- [ ] ⭐マークのホバー時にスタイルが変わる
- [ ] 記録がない日は通常表示（数字のみ）

### ポップアップ（記録詳細）

- [ ] ⭐マークをクリックするとポップアップが表示される
- [ ] ポップアップが画面中央に表示される
- [ ] ポップアップ背景にオーバーレイ（半透明黒背景）が表示される
- [ ] ポップアップ内に日付ヘッダーが表示される（例: 2025年11月24日）
- [ ] ポップアップ内にメニューリストが表示される（メニュー名: 回数）
- [ ] 閉じるボタンが存在する
- [ ] オーバーレイクリックでポップアップが閉じる
- [ ] 閉じるボタンクリックでポップアップが閉じる

### 月間移動

- [ ] 「前月」ボタンが存在し、常に有効
- [ ] 「次月」ボタンが存在する
- [ ] 「前月」ボタンクリックで1ヶ月前に移動する
- [ ] 「次月」ボタンクリックで1ヶ月後に移動する
- [ ] 現在月を表示中は「次月」ボタンが無効化される
- [ ] 月移動時に該当月の記録データが再取得される
- [ ] 1月の前月は前年12月に正しく移動する
- [ ] 12月の次月は翌年1月に正しく移動する

---

## データ取得・処理

### API 連携

- [ ] `/api/training-records` エンドポイントを使用
- [ ] クエリパラメータに `fromDate`（月初日）を指定
- [ ] クエリパラメータに `toDate`（月末日）を指定
- [ ] クエリパラメータに `limit=500` を指定
- [ ] ローディング中はスピナーが表示される
- [ ] エラー時はエラーメッセージが表示される

### データ集約

- [ ] API レスポンスを日付ごとにグループ化
- [ ] グループ化のキーは YYYY-MM-DD 形式
- [ ] 同じ日の記録が配列でまとめられている
- [ ] 記録がある日付が正しく判定される

## UI/UX 要件

### 視覚的デザイン

- [ ] Pure.css のスタイルと統一感がある
- [ ] カレンダーグリッドが整然と表示される

### 操作性

- [ ] カレンダーが1秒以内にレンダリングされる
- [ ] 記録データ取得が2秒以内に完了する
- [ ] ⭐クリックからポップアップ表示まで 0.3秒以内
- [ ] 月移動が スムーズ
- [ ] 前月/次月ボタンが押しやすい
- [ ] ポップアップが簡単に閉じられる
