## 実装ステップ

### Phase 1: カレンダーページの基本構造 (Priority: High)

#### 1.1 カレンダーページ作成

- `pages/calendar.tsx` を作成
- 基本的なページ構造を実装
- ヘッダー（年月表示 + 前月/次月ボタン）
- カレンダーグリッドのプレースホルダー

#### 1.2 カレンダーユーティリティ関数

- `src/utils/calendar.ts` を作成
- 月の日数を取得する関数
- 月初日の曜日を取得する関数
- カレンダーグリッド（週×日）を生成する関数
- 日付フォーマット関数（YYYY-MM-DD）

#### 1.3 型定義

- `src/types/calendar.ts` を作成
- `CalendarDay` 型（日付、現在月か、記録の有無など）
- `RecordsByDate` 型（日付ごとの記録集約）

**完了条件**:

- カレンダーページが表示される
- 年月ヘッダーが表示される
- 前月/次月ボタンが配置される（機能は未実装でOK）

### Phase 2: カレンダーグリッド表示 (Priority: High)

#### 2.1 Calendar コンポーネント作成

- `src/components/Calendar.tsx` を作成
- 現在表示中の年月を `useState` で管理
- カレンダーグリッド（7列×5〜6行）をレンダリング
- 月初・月末の埋め日を含む完全なグリッド表示

#### 2.2 CalendarDay コンポーネント作成

- `src/components/CalendarDay.tsx` を作成
- 日付番号を表示
- 現在日のハイライト表示
- 前月・次月の日付をグレーアウト
- Props: `date`, `isCurrentMonth`, `isToday`, `hasRecords`, `onClick`

#### 2.3 スタイリング

- `src/styles/calendar.css` を作成
- カレンダーグリッドのレイアウト（CSS Grid または Table）
- 日付セルのスタイル（サイズ、パディング、枠線）
- 現在日のハイライトスタイル
- 土曜日・日曜日の色分け（オプション）

**完了条件**:

- カレンダーグリッドが正しく表示される
- 現在日がハイライトされる
- 前月・次月の日付がグレーアウト表示される

---

### Phase 3: 記録データ取得と★マーク表示 (Priority: High)

#### 3.1 記録データ取得

- `pages/calendar.tsx` で `useEffect` を使用
- 表示中の月が変わったら API から記録データを取得
- `/api/training-records?fromDate=...&toDate=...&limit=500`
- ローディング状態とエラー状態を管理

#### 3.2 記録データの集約

- API レスポンスを日付ごとにグループ化
- `{ "2025-11-24": [record1, record2], ... }` 形式
- `Calendar` コンポーネントに渡す

#### 3.3 ★マーク表示

- `CalendarDay` コンポーネントで `hasRecords` prop を受け取る
- 記録がある日付に★マーク（`⭐`）を表示
- クリック可能なスタイル（カーソル変更、ホバー効果）

**完了条件**:

- 記録がある日付に★マークが表示される
- ローディング中はスピナーが表示される
- エラー時はエラーメッセージが表示される

---

### Phase 4: ポップアップ実装 (Priority: High)

#### 4.1 RecordPopup コンポーネント作成

- `src/components/RecordPopup.tsx` を作成
- ポップアップの基本構造（オーバーレイ + コンテンツ）
- Props: `date`, `records`, `onClose`
- 日付ヘッダー表示
- メニューリスト表示（メニュー名: 回数）
- 閉じるボタン

#### 4.2 ポップアップ開閉制御

- `Calendar` コンポーネントで選択日の state を管理
- ★マーククリック時に選択日をセット
- `RecordPopup` を条件付きレンダリング
- オーバーレイクリックで閉じる
- 閉じるボタンで閉じる

#### 4.3 スタイリング

- ポップアップのスタイル（中央配置、z-index）
- オーバーレイのスタイル（半透明黒背景）
- ポップアップアニメーション（フェードイン/アウト、オプション）

**完了条件**:

- ★クリックでポップアップが表示される
- その日の記録詳細が表示される
- オーバーレイまたは閉じるボタンでポップアップが閉じる

---

### Phase 5: 月間移動機能 (Priority: Medium)

#### 5.1 前月/次月ボタン実装

- 前月ボタンのクリックで表示月を1ヶ月前に変更
- 次月ボタンのクリックで表示月を1ヶ月後に変更
- 次月ボタンは現在月を表示中は無効化

#### 5.2 月変更時のデータ再取得

- 表示月が変わったら記録データを再取得
- `useEffect` の依存配列に年月を含める
- ローディング状態を表示

#### 5.3 年月の境界処理

- 1月の前月 → 前年12月
- 12月の次月 → 翌年1月
- 日付計算の正確性を確認

**完了条件**:

- 前月ボタンで過去月に遡れる
- 次月ボタンで現在月まで戻れる
- 現在月表示中は次月ボタンが無効
- 月変更時にデータが正しく再取得される

## 技術スタック

- **ページ**: Next.js Pages Router
- **コンポーネント**: React (TypeScript)
- **状態管理**: React useState, useEffect
- **API**: 既存 `/api/training-records` エンドポイント
- **スタイリング**: Pure.css + カスタム CSS
- **日付処理**: JavaScript Date オブジェクト（外部ライブラリ不使用）
- **テスト**: Jest + Testing Library

## リスクと対策

| リスク                   | 影響 | 対策                                 |
| ------------------------ | ---- | ------------------------------------ |
| API レスポンスが遅い     | 中   | ローディング表示、タイムアウト処理   |
| 記録データが大量         | 中   | limit 設定、ページング検討           |
| 日付計算のバグ           | 高   | 十分なテストケース、エッジケース確認 |
| スマホでのタップ領域不足 | 中   | 十分なパディング確保、実機テスト     |
