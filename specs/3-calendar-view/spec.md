# 機能仕様書: カレンダー表示機能

**機能ブランチ**: `3-calendar-view`
**作成日**: 2025-11-24
**ステータス**: Draft

## 概要

トレーニング記録を月次カレンダー形式で可視化する機能。
ユーザーは過去の記録を日単位で確認でき、トレーニング実施日を一目で把握できる。

## ユーザーシナリオとテスト

### ユーザーストーリー 1 - 月間カレンダー表示

ユーザーは現在月のカレンダーを表示し、トレーニング実施日を視覚的に確認できる。

**受け入れシナリオ**:

1. カレンダー画面を開くと、現在日が含まれる月のカレンダーが表示される
2. カレンダーは日曜日から土曜日までの週表示
3. 現在日はハイライト表示される（背景色や枠線で区別）
4. トレーニング記録がある日には★マークが表示される
5. 記録がない日は通常表示（数字のみ）

### ユーザーストーリー 2 - 記録詳細のポップアップ表示

ユーザーはトレーニング実施日をクリックして、その日の記録詳細を確認できる。

**受け入れシナリオ**:

1. ⭐マークがある日付をクリックすると、ポップアップが表示される
2. ポップアップには以下の情報が表示される
   - 対象日付（YYYY年MM月DD日）
   - その日に実施したメニュー一覧（メニュー名と回数）
   - 例: 「スクワット: 30回」「腕立て伏せ: 20回」
3. ポップアップ外側のオーバーレイをクリックすると閉じる
4. ポップアップ内の「閉じる」ボタンをクリックすると閉じる

### ユーザーストーリー 3 - 過去月への移動

ユーザーは過去の記録を振り返るため、前月に遡ってカレンダーを表示できる。

**受け入れシナリオ**:

1. カレンダーの上部に「前月」「次月」ボタンが表示される
2. 「前月」ボタンをクリックすると1ヶ月前のカレンダーに切り替わる
3. 連続して前月ボタンを押すことで、さらに過去に遡れる
4. 「次月」ボタンは、表示中の月が現在月より過去の場合のみ有効
5. 現在月を表示中は「次月」ボタンが無効化される（未来月には移動不可）
6. 月が切り替わると、その月の記録データが自動で再取得される

## 機能要件

### カレンダー表示

- 現在日が含まれる月を初期表示
- 日曜日〜土曜日の週単位でグリッド表示
- 月の最初の週は前月の日付で埋める（グレーアウト表示）
- 月の最後の週は次月の日付で埋める（グレーアウト表示）
- 現在日を視覚的に強調（背景色・枠線など）
- 土曜日は青色、日曜日は赤色でテキスト色を変更（オプション）

### トレーニング記録マーク

- API から対象月のトレーニング記録を取得
- 記録がある日付に⭐マークを表示
- 記録が複数ある日も⭐は1つのみ表示
- ⭐マークはクリック可能であることを示す（カーソル変更・ホバー効果）

### ポップアップ（モーダル）

- ⭐をクリックするとポップアップを画面中央に表示
- ポップアップ背景にオーバーレイ（半透明黒背景）
- ポップアップ内容:
  - 日付ヘッダー（例: 2025年11月24日）
  - メニューリスト（メニュー名: 回数）
  - 閉じるボタン
- オーバーレイクリックまたは閉じるボタンで非表示
- Escキーでも閉じられる（オプション）

### 月間移動

- 「前月」ボタン: 常に有効、1ヶ月前に移動
- 「次月」ボタン: 表示中の月が現在月の場合は無効化
- 月移動時に該当月の記録データを再取得
- 年月の表示（例: 2025年11月）
- 今月に戻るボタン（オプション）

## 成功基準

- カレンダーが1秒以内にレンダリングされる
- 記録データ取得が2秒以内に完了する
- ⭐マークのクリックからポップアップ表示まで 0.3秒以内
- 月移動時のデータ再取得が2秒以内
- スマホでも快適に操作できる（タップ領域が十分）

## エッジケース

### データ関連

- 記録データが0件の月は⭐マークなし
- API エラー時はエラーメッセージを表示し、再試行ボタンを提供
- ネットワーク遅延時はローディング表示

### UI/操作

- 前月の日付・次月の日付はクリック不可
- 現在月より未来の日付はクリック不可（⭐も表示されない）
- ポップアップ表示中も背景のカレンダーは見える（オーバーレイ透過）
- 複数のポップアップを同時に開かない

### 日付計算

- 月の境界を正しく処理（1月→前年12月、12月→翌年1月）
- うるう年を正しく処理（2月29日）
- タイムゾーンの考慮（サーバーとクライアントの日付のずれ）

## 主要コンポーネント

### `Calendar.tsx`

月間カレンダーのメインコンポーネント。

- 現在表示中の年月を state で管理
- 月間の記録データを取得・保持
- 日付グリッドを生成・レンダリング
- ポップアップの開閉制御

### `CalendarDay.tsx`

カレンダーの各日付セルコンポーネント。

- 日付番号を表示
- ★マークの表示判定
- クリックイベントハンドラ
- 現在日・前月・次月のスタイル切り替え

### `RecordPopup.tsx`

記録詳細を表示するポップアップコンポーネント。

- 指定日付の記録リストを表示
- オーバーレイ・閉じるボタンの実装
- Escキー対応（オプション）

## API 仕様

### `GET /api/training-records?fromDate=YYYY-MM-DD&toDate=YYYY-MM-DD`

**クエリパラメータ**:

- `fromDate`: 取得開始日（月初日）
- `toDate`: 取得終了日（月末日）
- `limit`: 500（月内の全記録を取得）

**レスポンス**:

```json
{
  "records": [
    {
      "id": "uuid",
      "training_menu_id": "uuid",
      "training_at": "2025-11-24T00:00:00Z",
      "count": 30,
      "training_menus": {
        "name": "スクワット"
      }
    }
  ],
  "total": 15
}
```

## データ処理

### 記録データの集約

- API から取得した records を日付ごとにグループ化
- キー: `YYYY-MM-DD` 形式の文字列
- 値: その日の記録配列
- 例: `{ "2025-11-24": [record1, record2], "2025-11-25": [record3] }`

### カレンダーグリッドの生成

- 指定月の1日の曜日を取得
- 月の日数を取得
- 前月・次月の埋め日を計算
- 7列×5〜6行のグリッド配列を生成

## スタイリング

- Pure.css テーブルをベースに使用
- カスタム CSS は `src/styles/calendar.css` に配置
- レスポンシブ対応:
  - PC: 7列グリッド、余白あり
  - スマホ: 7列グリッド、余白縮小、フォントサイズ調整

## 仮定

- 記録の `training_at` は UTC で保存、表示時にローカル日付に変換
- ⭐マークは絵文字（`⭐`）を使用
- カレンダーは `/calendar` パスでアクセス
- 既存の API エンドポイント `/api/training-records` を利用

## 依存関係

- 既存の `/api/training-records` API
- 既存の `TrainingRecord` 型定義
- 共通レイアウト（Header/Navigation）
- `apiClient` ユーティリティ

## 実装範囲外

- 週表示・日表示の切り替え
- カレンダーからの記録追加・編集・削除
- 記録の統計情報表示（合計回数・平均など）
- 複数月の一括表示
- カレンダーのエクスポート（PDF/画像など）
- 記録のフィルタリング（特定メニューのみ表示）
