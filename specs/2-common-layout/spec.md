# 機能仕様書: 共通レイアウトとナビゲーション

**機能ブランチ**: `2-common-layout`
**作成日**: 2025-11-24
**ステータス**: Draft

## 概要

アプリケーション全体で共通利用されるレイアウト、ヘッダーメニュー、ナビゲーションコンポーネントを提供する。
すべてのページで一貫したユーザー体験を実現し、画面間の移動を直感的に行えるようにする。

## ユーザーシナリオとテスト

### ユーザーストーリー 1 - 共通ヘッダーからのナビゲーション

ユーザーはどのページからでも、ヘッダーメニューを使って主要な画面に移動できる。

**受け入れシナリオ**:

1. ヘッダーにアプリケーション名（ロゴ）が表示される
2. ヘッダーに主要なナビゲーションリンクが表示される
   - ホーム（記録登録画面）
   - メニュー管理（メニュー一覧・新規作成）
3. 現在表示中のページがナビゲーション上で視覚的に識別できる（アクティブ状態の表示）
4. リンクをクリックすると対応するページに遷移する
5. ページ遷移時もヘッダーは常に表示され続ける

### ユーザーストーリー 2 - レスポンシブ対応

ユーザーはPC・スマートフォンどちらからでも快適にナビゲーションを利用できる。

**受け入れシナリオ**:

1. PC表示（幅 > 768px）では横並びのメニューリンクが表示される
2. スマホ表示（幅 <= 768px）ではハンバーガーメニューアイコンが表示される
3. ハンバーガーアイコンをタップするとメニューが展開される
4. メニュー展開中、再度アイコンをタップするとメニューが閉じる
5. メニューリンクをタップすると遷移し、メニューが自動で閉じる

## 機能要件

### ヘッダーコンポーネント

- アプリケーション名/ロゴを左端に表示
- ナビゲーションリンクを右側に配置
  - ホーム (`/`)
  - カレンダー表示(`/calendar`)
  - メニュー一覧 (`/training-menus`)
  - メニュー新規作成 (`/training-menus/new`)
  - 記録登録 (`/training-records/new`)
- 現在のページパスに応じてアクティブ状態を表示（背景色変更やアンダーライン）
- リンクはアイコンで分かりやすくする

#### 注意点

カレンダー表示は追加予定の機能

### レイアウトコンポーネント

- ヘッダー + メインコンテンツエリアの構造
- `<Layout>` コンポーネントですべてのページを包む
- メインコンテンツエリアに適切な padding/margin を適用
- Pure.css のグリッドシステムと整合性を保つ

### レスポンシブ対応

- PC表示: 横並びナビゲーション
- スマホ表示: ハンバーガーメニュー + ドロワー展開
- ブレークポイント: 768px

## 成功基準

- すべてのページで一貫したヘッダーが表示される
- ナビゲーションリンクのクリックから 0.5 秒以内にページ遷移が開始される
- スマホ表示でもメニュー操作が快適に行える
- 現在ページが視覚的に分かりやすい

## エッジケース

- 存在しないパスへのリンクは 404 ページに遷移
- ページ遷移中もヘッダーがちらつかない（レイアウトシフトなし）
- メニュー展開中に画面サイズ変更した場合は適切に再レンダリング

## 主要コンポーネント

### `Layout.tsx`

すべてのページを包むコンテナコンポーネント。

```tsx
<Layout>
  <Header />
  <main>{children}</main>
</Layout>
```

### `Header.tsx`

ヘッダーとナビゲーションを含むコンポーネント。

### `Navigation.tsx`

ナビゲーションリンクのリスト。PC/スマホで表示を切り替え。

## スタイリング

- Pure.css の標準スタイルをベースに使用
- カスタム CSS は `src/styles/layout.css` に配置
- レスポンシブ対応は CSS メディアクエリで実装

## 仮定

- Next.js の `_app.tsx` で `<Layout>` をすべてのページに適用
- ナビゲーションはクライアントサイドルーティング（`next/link`）を使用
- 認証機能は現時点では不要（将来追加の可能性あり）

## 依存関係

- 既存ページ（`pages/index.tsx`, `pages/training-menus/new.tsx`, `pages/training-records/new.tsx` など）
- Pure.css（スタイリング）
- Next.js Link コンポーネント

## 実装範囲外

- ユーザー認証・ログイン状態の表示
- フッターコンポーネント（必要に応じて将来追加）
- ダークモード切替
- 多言語対応
