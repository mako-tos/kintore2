# 実装計画: 共通レイアウトとナビゲーション

**機能**: 共通レイアウトとナビゲーション  
**作成日**: 2025-11-24  
**ステータス**: Draft

## 実装ステップ

### Phase 1: 基本レイアウトとヘッダー構造 (Priority: High)

#### 1.1 Layout コンポーネント作成

- `src/components/Layout.tsx` を作成
- Header + main コンテンツエリアの基本構造を実装
- Pure.css グリッドとの整合性確保

#### 1.2 Header コンポーネント作成

- `src/components/Header.tsx` を作成
- アプリケーション名/ロゴ表示
- PC 向け横並びナビゲーションの実装

#### 1.3 \_app.tsx への統合

- `pages/_app.tsx` で全ページに `<Layout>` を適用
- 既存ページが正しく表示されることを確認

**完了条件**:

- すべてのページで共通ヘッダーが表示される
- ナビゲーションリンクから各ページに遷移できる

---

### Phase 2: ナビゲーション機能実装 (Priority: High)

#### 2.1 Navigation コンポーネント作成

- `src/components/Navigation.tsx` を作成
- Next.js `Link` を使用したルーティング実装
- ナビゲーション項目の定義（ホーム、メニュー管理、記録登録）

#### 2.2 アクティブページのハイライト

- `useRouter` で現在のパスを取得
- 現在ページのリンクに視覚的な区別を追加（`active` クラス適用）

#### 2.3 スタイリング

- `src/styles/layout.css` を作成
- ヘッダー、ナビゲーションリンクのスタイル定義
- Pure.css との整合性を保ちつつカスタマイズ

**完了条件**:

- 現在表示中のページがナビゲーション上で識別できる
- リンククリックでスムーズにページ遷移する

---

### Phase 3: レスポンシブ対応 (Priority: Medium)

#### 3.1 ハンバーガーメニュー実装

- スマホ表示用のメニュートグルボタンを追加
- メニュー開閉状態を `useState` で管理
- メニューアイコン（☰）の表示/非表示切り替え

#### 3.2 ドロワーメニュー実装

- メニュー展開時のオーバーレイ表示
- メニューリンク一覧を縦並びで表示
- リンククリック時にメニューを自動で閉じる

#### 3.3 メディアクエリ設定

- PC表示（> 768px）: 横並びナビゲーション
- スマホ表示（<= 768px）: ハンバーガーメニュー
- CSS でブレークポイントを設定

**完了条件**:

- PC/スマホ両方で適切にナビゲーションが表示される
- スマホでハンバーガーメニューが正しく動作する

---

### Phase 4: テストとリファクタリング (Priority: Medium)

#### 4.1 コンポーネント単体テスト

- `Header.test.tsx` を作成
- ナビゲーションリンクのレンダリング確認
- アクティブ状態の正しい適用を検証

#### 4.2 E2E 的な動作確認

- 各ページへの遷移が正しく動作するか手動テスト
- レスポンシブ表示の動作確認（ブラウザの開発者ツール使用）

#### 4.3 パフォーマンス最適化

- 不要な再レンダリングを防ぐ（`memo` の適用検討）
- CSS の最適化（不要なスタイルの削除）

**完了条件**:

- すべてのテストがパスする
- パフォーマンス上の問題がない

---

## 技術スタック

- **コンポーネント**: React (TypeScript)
- **ルーティング**: Next.js Link, useRouter
- **スタイリング**: Pure.css + カスタム CSS
- **状態管理**: React useState (メニュー開閉のみ)
- **テスト**: Jest + Testing Library
