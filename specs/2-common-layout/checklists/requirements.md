## 機能要件

### ヘッダーコンポーネント

- [ ] アプリケーション名/ロゴが左端に表示される
- [ ] ナビゲーションリンクが右側に配置される
- [ ] ホーム (`/`) へのリンクが存在する
- [ ] カレンダー表示(`/calendar`) へのリンクが存在する
- [ ] メニュー新規作成 (`/training-menus/new`) へのリンクが存在する
- [ ] 記録登録 (`/training-records/new`) へのリンクが存在する
- [ ] 現在のページに応じてアクティブ状態が表示される
- [ ] アクティブ状態は視覚的に明確（背景色変更やアンダーライン）

### レイアウトコンポーネント

- [ ] `Layout` コンポーネントですべてのページが包まれている
- [ ] ヘッダー + メインコンテンツの構造が正しく実装されている
- [ ] メインコンテンツエリアに適切な padding/margin が適用されている
- [ ] Pure.css のグリッドシステムと整合性が保たれている

### ナビゲーション機能

- [ ] すべてのナビゲーションリンクがクリック可能
- [ ] リンククリックで対応するページに遷移する
- [ ] ページ遷移時もヘッダーは常に表示され続ける
- [ ] ページ遷移時にレイアウトシフトが発生しない

---

## レスポンシブ対応

### PC 表示（幅 > 768px）

- [ ] 横並びのメニューリンクが表示される
- [ ] ハンバーガーメニューアイコンは非表示
- [ ] すべてのリンクが一目で確認できる
- [ ] ホバー時のスタイルが適用される

### スマホ表示（幅 <= 768px）

- [ ] ハンバーガーメニューアイコン（☰）が表示される
- [ ] 横並びメニューは非表示
- [ ] アイコンタップでメニューが展開される
- [ ] メニュー展開中、再度タップでメニューが閉じる
- [ ] メニューリンクタップで遷移し、メニューが自動で閉じる
- [ ] オーバーレイ背景タップでメニューが閉じる

---

## UI/UX 要件

### 視覚的デザイン

- [ ] Pure.css のスタイルと統一感がある
- [ ] ヘッダーの背景色が適切
- [ ] リンクのテキストが読みやすい
- [ ] アクティブ状態が明確に識別できる
- [ ] ホバー時のフィードバックが適切

### 操作性

- [ ] リンククリックから 0.5 秒以内にページ遷移が開始される
- [ ] スマホでのタップ操作が快適
- [ ] ハンバーガーメニューの開閉がスムーズ
- [ ] 誤タップを防ぐ適切なタップ領域が確保されている

---

## 非機能要件

### パフォーマンス

- [ ] ヘッダーのレンダリングが高速（100ms 以内）
- [ ] 不要な再レンダリングが発生しない
- [ ] CSS のファイルサイズが適切（< 10KB）
- [ ] バンドルサイズへの影響が最小限

### アクセシビリティ

- [ ] ナビゲーションリンクに適切な `aria-label` が設定されている（オプション）
- [ ] ハンバーガーメニューボタンに `aria-expanded` が設定されている（オプション）
- [ ] キーボード操作（Tab, Enter）でナビゲーションが利用できる
- [ ] フォーカス状態が視覚的に明確

### ブラウザ対応

- [ ] Chrome（最新版）で正しく動作する
- [ ] Firefox（最新版）で正しく動作する
- [ ] Safari（最新版）で正しく動作する
- [ ] Edge（最新版）で正しく動作する
- [ ] モバイル Safari で正しく動作する
- [ ] モバイル Chrome で正しく動作する
