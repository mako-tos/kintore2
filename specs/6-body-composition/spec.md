# spec: 体組成情報登録画面

- 機能名: 体組成情報登録
- 作成日: 2025-12-21
- 作成者: GitHub Copilot

## 概要

ユーザーが体組成計の計測結果ファイル（.mht形式）をアップロードし、その内容を解析して体組成情報を登録する機能。

## 画面構成

### 1. ファイル選択エリア

- **ファイル選択ボタン**: `.mht` ファイルを選択するための `<input type="file">`。
- **説明文**: 「体組成計の結果ファイル（.mht）を選択してください」等の案内。

### 2. プレビュー・確認エリア

ファイル読み込み成功後に表示される。各項目はフォームの入力フィールドとして表示し、必要に応じて修正可能とする（または readonly で表示し、確認のみとする）。
要件は「読み込み画面表示」→「確認後に送信」なので、初期値として読み込んだ値をセットしたフォームを表示するのが適切。

| 項目名     | 表示タイプ         | 初期値                              | 備考                                 |
| :--------- | :----------------- | :---------------------------------- | :----------------------------------- |
| 計測日     | Date Picker / Text | ファイルから抽出した日時            | 必須。フォーマット: YYYY/MM/DD HH:mm |
| 体重       | Number Input       | ファイルから抽出した体重 (kg)       | 必須。単位: kg                       |
| 体脂肪量   | Number Input       | ファイルから抽出した体脂肪量 (kg)   | 必須。単位: kg                       |
| 除脂肪体重 | Number Input       | ファイルから抽出した除脂肪体重 (kg) | 必須。単位: kg                       |
| 筋肉量     | Number Input       | ファイルから抽出した筋肉量 (kg)     | 必須。単位: kg                       |

### 3. アクションエリア

- **送信ボタン**: フォームの内容をデータベースに保存する。
- **キャンセルボタン**: 入力を破棄して戻る（任意）。

## 処理ロジック

### 1. ファイル読み込みと解析 (Client Side)

ユーザーがファイルを選択したタイミング、またはアップロードボタンを押したタイミングで実行。

1.  **ファイル読み込み**: `FileReader` API 等を使用して、選択された `.mht` ファイルをテキストとして読み込む。
2.  **HTML抽出**: MHTML形式のテキストから、`Content-Type: text/html` のパートを抽出する。
    - 簡易的には、`<!DOCTYPE html>` から `</html>` までを文字列操作で切り出し、`DOMParser` に渡す方針とする。
    - `quoted-printable` や `base64` でエンコードされている場合はデコードが必要だが、サンプルの `.mht` は `Content-Transfer-Encoding: binary` なのでそのまま読める可能性が高い。ただし、MHTMLの仕様上、エンコーディングのチェックは必要。
3.  **データ抽出 (Parsing)**:
    - `DOMParser` を使用して HTML 文字列を DOM に変換する。
    - 以下のセレクタ・ロジックでデータを抽出する。
    - **注意**: 数値項目には "KG" などの単位が含まれる場合があるため、正規表現等で数値部分のみを抽出して `parseFloat` する必要がある。

    | 項目           | 抽出ロジック (例)                                                                                                                                                                                            |
    | :------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | **計測日**     | `div.report-view-header-item` の中から "時間：" で始まるテキストを探し、"時間：" 以降の日時文字列をパースする。<br>例: `時間：2025-12-20 10:40:29` -> `2025-12-20T10:40:29` (YYYY-MM-DD HH:mm:ss 形式を想定) |
    | **体重**       | `div.u-row.value` の中で、最初の子要素(`div`)のテキストが "体重" であるものを探す。<br>その行の2番目の `div` 内の数値テキストを取得。<br>例: `74.6`                                                          |
    | **体脂肪量**   | `div.u-row.value` の中で、最初の子要素のテキストが "体脂肪量" であるものを探す。<br>その行の2番目の `div` 内の数値テキストを取得。<br>例: `18.6`                                                             |
    | **除脂肪体重** | `div.u-row.value` の中で、最初の子要素のテキストが "除脂肪体重" であるものを探す。<br>その行の2番目の `div` 内の数値テキストを取得。<br>例: `56`                                                             |
    | **筋肉量**     | `div.u-row.value` の中で、最初の子要素のテキストが "筋肉量" であるものを探す。<br>その行の2番目の `div` 内の数値テキストを取得。<br>例: `52.2`                                                               |

4.  **エラーハンドリング**:
    - 必須項目が見つからない場合や、パースに失敗した場合はエラーメッセージを表示する。

### 2. データ登録 (Server Side)

- **API エンドポイント**: `POST /api/body-compositions` (仮)
- **リクエストボディ**:
  ```json
  {
    "date": "2025-12-20T10:40:29.000Z",
    "weight": 74.6,
    "bodyFatMass": 18.6,
    "leanBodyMass": 56.0,
    "muscleMass": 52.2
  }
  ```
- **処理**:
  - 認証済みユーザーのID (`userId`) を取得。
  - `BodyComposition` テーブルにレコードを挿入。
- **レスポンス**:
  - 成功時: 201 Created, 作成されたレコード情報。
  - 失敗時: 400 Bad Request (バリデーションエラー等), 500 Internal Server Error。
