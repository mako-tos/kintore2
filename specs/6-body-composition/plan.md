# plan: 体組成情報登録機能

- 機能名: 体組成情報登録
- 作成日: 2025-12-21
- 作成者: GitHub Copilot

## 概要

体組成計の計測結果ファイル（.mht）を読み込み、体組成情報をデータベースに登録する機能を実装する。

## 実装計画

### Phase 1: データベース構築

1.  **マイグレーションファイルの作成**
    - `supabase/migrations` 配下に新しい SQL ファイルを作成する。
    - `body_compositions` テーブルを作成する。
    - RLS (Row Level Security) ポリシーを設定する（ユーザーは自分のデータのみ参照・追加可能）。

2.  **型定義の更新**
    - `npm run generate-types` を実行し、Supabase の型定義を更新する。
    - `src/types/body-composition.ts` (または `d.ts`) を作成し、アプリケーション内で使用する型を定義する。

### Phase 2: バックエンド API 実装

1.  **API ルートの作成**
    - `src/pages/api/body-compositions/index.ts` を作成する。
    - `POST` メソッドを実装し、リクエストボディのバリデーションと DB への保存処理を行う。
    - 認証チェック (`supabase-server.ts` 等を使用) を組み込む。

### Phase 3: フロントエンド実装 (ロジック)

1.  **MHT 解析ユーティリティの実装**
    - `src/utils/mht-parser.ts` を作成する。
    - `.mht` ファイルのテキストコンテンツから HTML 部分を抽出する関数を実装する。
    - HTML 文字列から必要なデータ（計測日、体重、体脂肪量、除脂肪体重、筋肉量）を抽出する関数を実装する。
    - ユニットテスト (`src/utils/__tests__/mht-parser.test.ts`) を作成し、サンプルファイルを用いて解析ロジックを検証する。

### Phase 4: フロントエンド実装 (UI)

1.  **登録ページコンポーネントの作成**
    - `src/pages/body-composition/index.tsx` (一覧兼登録画面) または `src/pages/body-composition/new.tsx` を作成する。
    - レイアウトコンポーネントを適用する。

2.  **ファイルアップロードコンポーネントの実装**
    - ファイル選択ボタンを配置する。
    - ファイル選択時に `FileReader` で読み込み、解析ユーティリティを呼び出す処理を実装する。

3.  **登録フォームの実装**
    - 解析結果を表示するフォームを作成する（初期値として解析結果をセット）。
    - 各項目を編集可能にする。
    - 送信ボタン押下時に API を呼び出す処理を実装する。

### Phase 5: 結合テスト・確認

1.  **E2E テスト / 手動確認**
    - 実際に `.mht` ファイルをアップロードし、解析結果が正しく表示されるか確認する。
    - 登録処理を行い、DB にデータが保存されるか確認する。

## 完了条件

- `body_compositions` テーブルが作成されていること。
- `.mht` ファイルから正しくデータが抽出できること。
- 抽出したデータを画面で確認・修正し、登録できること。
- 登録したデータがデータベースに保存されていること。
